# Public adapter template

These are legacy reference snippets, not an installable skill bundle. Use `ohf init` for a complete current scaffold with `SKILL.md`, the authoritative manifest, schemas and resources. The current generator uses installed package resources; it does not read this directory. The adapter example remains a dry run.

This template is a neutral bridge. Replace the `UNRESOLVED` fields only with evidence from the algorithm's public documentation. Keep source code, user data, credentials, private paths, and deployment-only configuration outside the public bundle.
